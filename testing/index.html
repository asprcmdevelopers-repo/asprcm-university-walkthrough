T06 Course 1: final exam questions (all 6 types)

Sign in as
superadmin@asprcm.com
Go to
Final exam tab → Questions → + Add question

Steps

  1. Q1, then Save question.

    FieldEnter / choose
    Type Single choice
    Question CO-97 means?
    Add a scenario Ticked: A $1,200 claim came back with code CO-97.
    Options Bundled service ✔ · Missing information · Not covered
    Marks 1
    Topic Denials
    Difficulty Easy
    Explanation CO-97 = the service is bundled with another.

  2. Q2:

    FieldEnter / choose
    Type Multiple answers
    Question What belongs on a corrected claim?
    Options Correct NPI ✔ · Frequency code 7 ✔ · Original claim number ✔ · Random code
    Topic Claims (check "Denials" is suggested)

  3. Q3:

    FieldEnter / choose
    Type True / False
    Question You should resubmit without fixing the error.
    Correct answer False
    Topic Denials

  4. Q4:

    FieldEnter / choose
    Type Fill in the blank
    Question The payer's response to a claim is the ___.
    Accepted answers EOB, + Add → ERA
    Topic claims (lowercase: should save as "Claims")

  5. Q5:

    FieldEnter / choose
    Type Match the following
    Question Match each code to its meaning.
    Pairs CO-16 → Missing information · CO-97 → Bundled service · + Add pair: CO-50 → Not medically necessary
    Topic Denials

  6. Q6:

    FieldEnter / choose
    Type Put in order
    Question Put the denial steps in order.
    Steps Read the denial code · Fix the claim · Resubmit · Track the response
    Topic Claims
